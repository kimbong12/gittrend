"깃허브(GitHub)가 뭐길래 다들 이야기할까요?"

깃허브는 전 세계 천재 개발자들이 만든 기가 막힌 소프트웨어와 AI 도구의 '요리 레시피(소스코드)'를 무료로 공개해 둔 거대한 도서관입니다. 코드를 몰라도 누구나 이 레시피를 복사해 내 컴퓨터나 웹사이트에서 바로 써먹을 수 있습니다.

01

내 마음에 드는 프로젝트 고르기

상단 [인기 저장소] 탭에서 지금 스타가 많이 붙고 있는 AI 도구나 자동화 프로그램을 구경하세요. '핵심 분석'과 '실무 응용' 카드를 보면 어떤 용도로 쓸 수 있는지 쉽게 파악할 수 있습니다.

02

설치 없이 웹 브라우저에서 바로 체험

복잡한 프로그램 설치가 무섭다면, 깃허브 저장소 주소에서 github.com을 github.dev로 바꾸고 엔터를 쳐보세요! 크롬 브라우저 안에서 코드를 실시간으로 만져볼 수 있습니다.

03

내 컴퓨터로 파일 다운로드 (ZIP)

깃허브 저장소 페이지에서 초록색 `Code` 버튼을 누른 뒤 `Download ZIP`을 클릭하면 압축 파일 형태로 소스코드를 통째로 받을 수 있습니다.

04

마법의 3줄 실행 주문 (치트시트)

압축을 푼 폴더에서 터미널(명령 프롬프트)을 열고, 프로젝트 종류에 따라 아래 3줄만 순서대로 붙여넣으면 대부분 바로 실행됩니다.

🐍 파이썬(Python) 프로젝트: pip install -r requirements.txt
python main.py
🌐 웹/노드(Node.js) 프로젝트: npm install
npm run dev
05

무료로 나만의 웹사이트/앱 출시하기

내 컴퓨터에서만 실행되는 게 아니라 다른 사람들에게도 공유하고 싶다면 무료 호스팅 서비스를 사용하세요.

• GitHub Pages: 포트폴리오, 회사 소개 페이지 등을 무료 영구 도메인으로 배포.

• Vercel / Netlify: 깃허브 계정으로 로그인 후 저장소만 선택하면 30초 만에 실시간 주소 발급.

• Streamlit Community Cloud: 파이썬 AI 대시보드를 클릭 한 번으로 배포.

에러가 나면 어떻게 하나요?

1. 빨간 에러 메시지를 통째로 복사해서 제미나이/챗GPT에 붙여넣고 "비전공자인데 이 에러 어떻게 해결해?"라고 묻기.

2. 저장소 상단의 Issues 탭을 누르고 에러 단어를 검색하면 전 세계 사용자들이 이미 올린 해결책이 나옵니다.
