코딩을 1줄도 몰라도 따라할 수 있는 깃허브 입문서

"깃허브(GitHub), 비전공자도 쉽게 쓸 수 있나요?"

네! 깃허브는 개발자들만의 전유물이 아닙니다. 전 세계 수백만 명의 천재들이 만든 최신 AI 프로그램, 자동화 도구, 유용한 웹 앱을 무료 레고 블록처럼 가져와 내 생활과 비즈니스에 바로 써먹을 수 있는 보물창고입니다. 아래 5단계만 읽어보세요.

01

깃허브는 '오픈소스 요리 레시피'

요리사가 레시피와 재료를 인터넷에 공개하듯, 전 세계 프로그래머들이 자기가 만든 프로그램의 설계도(소스코드)를 투명하게 공개해 둔 거대한 클라우드 도서관입니다. 누구나 무료로 복사해서 쓸 수 있습니다.

💡 꼭 알아야 할 3단어:

• Repository(저장소): 하나의 프로젝트 폴더

• Star(별표): 유튜브의 '좋아요'나 즐겨찾기

• Fork(포크): 남의 프로젝트를 내 계정으로 통째로 복사

02

내 컴퓨터 설치 없이 웹에서 바로 실행

복잡한 프로그램 깔기 두려우신가요? 깃허브에는 브라우저에서 버튼 하나만 누르면 가상의 고성능 클라우드 컴퓨터를 띄워주는 기능이 있습니다.

단축키 점 (.) 저장소 화면에서 키보드 점(.)을 누르면 웹 VS Code가 열립니다!

• GitHub Codespaces: 녹색 Code 버튼 → Codespaces 탭 클릭 시 무료로 웹 실행 환경 제공.

03

내 컴퓨터로 소스코드 통째로 가져오기

어려운 명령어 없이 일반 파일 다운로드하듯 프로젝트를 가져올 수 있습니다.

초보자 추천: 저장소 우측 상단 녹색 <> Code 버튼 클릭 → Download ZIP 클릭 후 압축 해제.
터미널 사용 시: git clone [주소] 한 줄이면 5초 만에 복사 완료!
04

마법의 3줄 실행 주문 (치트시트)

압축을 푼 폴더에서 터미널(명령 프롬프트)을 열고, 프로젝트 종류에 따라 아래 3줄만 순서대로 붙여넣으면 대부분 바로 실행됩니다.

🐍 파이썬(Python) 프로젝트: pip install -r requirements.txt
python main.py
🌐 웹/노드(Node.js) 프로젝트: npm install
npm run dev
05

무료로 나만의 웹사이트/앱 출시하기

내 컴퓨터에서만 실행되는 게 아니라 다른 사람들에게도 공유하고 싶다면 무료 호스팅 서비스를 사용하세요.

• GitHub Pages: 포트폴리오, 회사 소개 페이지 등을 무료 영구 도메인으로 배포.

• Vercel / Netlify: 깃허브 계정으로 로그인 후 저장소만 선택하면 30초 만에 실시간 주소 발급.

• Streamlit Community Cloud: 파이썬 AI 대시보드를 클릭 한 번으로 배포.

FAQ

에러가 나면 어떻게 하나요?

초보자에게 빨간색 에러 메시지는 당연합니다! 당황하지 마시고 이렇게 대처하세요.

1. 빨간 에러 메시지를 통째로 복사해서 제미나이/챗GPT에 붙여넣고 "비전공자인데 이 에러 어떻게 해결해?"라고 묻기.

2. 저장소 상단의 Issues 탭을 누르고 에러 단어를 검색하면 전 세계 사용자들이 이미 올린 해결책이 나옵니다.
